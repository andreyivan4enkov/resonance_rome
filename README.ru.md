# Resonance-Weighted ROME

Пилот на GPT-2-small: в формуле ROME/MEMIT меняется только ковариация `C` —
вместо статистики корпуса берётся резонанс (топология + асимметричный
перенос бюджета слабый→сильный).

**Статус:** воспроизводимый черновик. Не COUNTERFACT/zsRE, не рецензия,
не проверка на моделях крупнее GPT-2-small.

Полный текст, таблицы и отрицательные результаты — в
[английской README](README.md). Определения — [`docs/METHODS.md`](docs/METHODS.md).
Хронология, включая провалы — [`docs/JOURNEY.md`](docs/JOURNEY.md).
Сырой журнал сессии — локальный sandbox (`D:\RLM\_external\sandbox`).
